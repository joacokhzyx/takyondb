# Ejemplos relacionales

Diez programas ejecutables, todos typechecked **y ejecutados** por
`node scripts/examples_check.js` (integrado en el workflow
`Relational Checks`), de modo que ningún ejemplo puede pudrirse en silencio.

Ver [README.md](README.md) de este directorio para la tabla de contenidos y
cómo ejecutar cada uno.
